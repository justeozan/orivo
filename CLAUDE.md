# Orivo

Avant toute interface (un panneau, un écran, un texte affiché), lire `docs/DESIGN.md`. Pour Settings et les plugins, c'est **§4.4** qui fait foi : limpide, visuel, compact, épuré.

- Pas de paragraphe dans un panneau. Un libellé fait 1 à 3 mots, un état est une pastille, un bouton est un verbe.
- Une ligne par chose, ce qui est prêt replié, l'avancé dans un `<details>` fermé, une collection en grille de cartes.
- Un bouton lance la commande dans Orivo (pas de Terminal, rien à copier), sans poser de question ; la sortie s'affiche sous la ligne, le log complet derrière un chevron.
- Reprendre les composants listés au §4.4 plutôt qu'en créer un nouveau.
- Les garanties et les modes d'emploi vont dans `docs/`, pas à l'écran.
