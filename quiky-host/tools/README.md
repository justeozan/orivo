# Host tools

These are Windows/Wine tools used by the FitGirl installer. They are host-side
only; none of them is packaged into the `.orivo-plugin` archive.

| File | Purpose | Source |
| --- | --- | --- |
| `unarc_extract.c` | 32-bit helper that loads `unarc.dll` and calls `FreeArcExtract` with a destination path. | This repository. Build with `make build-wine-helper`. |
| `bin/unarc_extract.exe` | Built helper. Generated by `make build-wine-helper`; ignored by git. | `unarc_extract.c` |
| `bin/srep.exe` | Standalone SREP 3.x decoder. Used through `arc.ini` because the CLS SREP plugin hangs under Wine. | FreeArc 0.67. See `SREP-LICENSE.txt`. |
| `bin/unarc` | Patched native FreeArc `UnArc` (macOS arm64) used as a fallback when `unarc.dll` rejects stale archive CRCs. | FreeArc 0.666 sources. See `FREearc-LICENSE.txt`. |

The helper must run with its executable in the same directory as
`unarc.dll` and the setup DLLs. `host/rust/src/fitgirl.rs` copies it into the
per-install tools directory for exactly that reason.

The native `unarc` binary is built for macOS arm64. On other hosts, build the
patched `UnArc` from FreeArc sources and point `QUIKY_NATIVE_UNARC` at it (or
replace `bin/unarc`). The native fallback is optional; without it, archives
whose stored CRCs do not match (for example `fg-01.bin`) cannot be extracted.
